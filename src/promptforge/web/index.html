常见问题 · 增强失败怎么办
鉴权失败（400）：API Key 无效或无权限——检查「连接参数」里的 Key 是否过期、是否误粘了引号。
触发限流（429）：厂商侧流量保护——等待 1 分钟再试，或换更高配额的模型/账号。
模型返回为空：已自动重试 2 次仍为空——换一个模型，或检查 Base URL 是否指向了 /chat/completions 兼容端点。
超时（504）：请求超过 90 秒——网络拥塞或模型排队，稍后重试。
质量偏低：结果与原文相似度过高会被标记——把输入写得更具体（背景/目标/约束/格式）再试。
